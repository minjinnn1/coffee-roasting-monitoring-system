# Industrial Monitoring and Control System for Coffee Bean Roasting

Bachelor's capstone project focused on developing an industrial monitoring and control system for coffee bean roasting.

## Technologies

- MySQL
- Node.js
- Express.js
- JavaScript
- HTML
- CSS

## Features

- Real-time monitoring
- SQL database
- Recipe management
- Alarm system
- User authentication
